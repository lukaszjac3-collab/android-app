# android-app

Gotowe pliki APK aplikacji Android (kod źródłowy jest w prywatnych repozytoriach).

| Katalog | Aplikacja |
|---|---|
| `agromanager/` | AgroManager — aplikacja do serwisu AgroManager (logowanie kodem QR) |

W katalogu aplikacji:
- `latest.json` — najnowsza wersja (`wersja`, `kod`, `plik`, `url`, `rozmiar`, `sha256`, `data`, `opis`); z niego aplikacja sprawdza aktualizacje,
- `agromanager-1.N.apk` — trzy najnowsze wersje.

Pliki publikuje automatycznie GitHub Actions po zbudowaniu aplikacji. Nie edytuj ich ręcznie.
